Aplicação simples em **Streamlit** para visualização de dados de vendas.

## 🔍 Funcionalidades

- Visualização do dataframe completo
- Gráficos por estado, mês e categoria
- Ranking de vendedores
- Download de CSV

## 🚀 Como executar

1. Crie o ambiente virtual:

```bash
python -m venv .venv
```

2. Ative o ambiente virtual (Windows):

```bash
.venv\Scripts\activate
```

3. Ative o ambiente virtual (Linux/Mac):

```bash
source .venv/bin/activate
```

4. Instale as dependências:

```bash
pip install -r requirements.txt
```

5. Inicie o app:

```bash
streamlit run app.py
```

6. **Importante**\
   O arquivo `vendas.json` deve estar dentro da pasta:

```
dados/
```
